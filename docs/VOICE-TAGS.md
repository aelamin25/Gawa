# How Pengu says each line (the feeling tags)

Every line Pengu can show carries a feeling tag. The voice acts the tag: pace, how high it sits, how loud, and how the
pitch moves inside a sentence (questions rise, sad lines fall, excited ones start bright). The tags come from the face
each family shows (`tools/list_lines.cpp`), the tones are set in `tools/make_speech.py` (`TONES`). Change a tone there,
run `make_speech.py`, flash `speech.bin`.

| Tag | How it sounds | Lines |
|---|---|---|
| sad | slowest, lower, softer, falls at the end | 50 |
| thoughtful | slow, a touch lower, longer pauses | 36 |
| loving | a bit slower, warm, soft landings | 29 |
| calm | slow, quiet, gentle fall | 26 |
| excited | quick, bright, a bounce on the exclamations | 23 |
| happy | light and warm, questions rise | 18 |
| sleepy | slow, low, quiet | 15 |
| grumpy | a touch lower, settles down | 15 |
| curious | normal pace, questions rise the most | 13 |
| shy | quieter, a touch higher | 13 |
| confident | steady, a touch louder | 12 |
| scared | quick, high, quiet | 10 |
| nervous | a little quick and high | 10 |
| proud | a little louder, steady | 7 |
| playful | quick, high, cheeky | 7 |
| relieved | slower, settling | 6 |
| angry | punchy, a little louder | 3 |
